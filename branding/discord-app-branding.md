# Serene Nursery Discord LogBot Branding

## Discord Developer Portal

App name:

```text
Serene Nursery LogBot
```

Short description:

```text
A cozy flower collection logger for Serene Nursery's Cosy Florist players.
```

Long description:

```text
Serene Nursery LogBot helps our private Discord server track Cozy Florist flower collections without spreadsheet juggling. Players can log owned flowers, search who has a flower, check quest points and rarity, pin wishlist flowers, and view collection progress. Admin tools keep the flower catalogue and player data tidy as the nursery grows.
```

Tagline:

```text
Log flowers, find collectors, and keep the nursery blooming.
```

Suggested tags:

```text
flowers, collection, cozy, utility, private-server
```

Primary command pitch:

```text
Use /log to add flowers, /find to see who owns one, /count to check progress, and /pinned to keep track of wishlist flowers.
```

Admin command pitch:

```text
Admins can add flowers, manage app admins, review pinned flower demand, and bulk-add matching flowers for players.
```

Icon concept:

```text
A soft garden flower and checked nursery tag, combining cozy collection progress with flower catalogue tracking.
```

Generation prompt:

```text
Create a polished Discord application icon for Serene Nursery Discord LogBot: a centered cozy flower emblem with coral-pink petals, green leaves, and a small cream garden tag/logbook charm with a green checkmark. Use a full-bleed light mint-to-cream square background, crisp small-size readability, no text, no Discord logo, no copyrighted game logo, and no black or transparent corners.
```

Voice:


Deployment checklist:

```text
1. Upload branding/serene-nursery-discord-app-icon-1024.png as the Discord App Icon.
2. Use "Serene Nursery LogBot" as the app display name.
3. Add the short description and long description above in the Developer Portal.
4. Confirm the Interactions Endpoint URL is https://bot.serenenursery.pipeitc.dev/api/interactions.
5. Re-register slash commands after any command description changes with npm run discord:register.
```
